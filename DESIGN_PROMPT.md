# Промпт для генерации Bot Stat Page изображения

## Технические характеристики
- **Размер:** 960x540 px (16:9)
- **Формат:** PNG или JPG
- **Стиль:** В соответствии с https://dev.uspeshnyy.ru/www/tulaev/

---

## Промпт для AI генератора изображений

### Основной промпт (English):

```
Create a modern minimalist banner image 960x540px for a neuroscience quiz bot telegram page.

STYLE:
- Clean white/light background with subtle gradient
- Futuristic sci-fi aesthetic with neon accents
- Professional and scientific vibe
- High-tech neural network theme

COLOR PALETTE:
- Base: White (#FFFFFF) to light gray (#F5F5F5) gradient background
- Primary accents: Electric blue (#00B4FF), neon purple (#8B5CF6)
- Secondary: Subtle mint green (#10B981) for highlights
- Text: Dark charcoal (#1F2937)

VISUAL ELEMENTS:
- Abstract brain outline made of connected dots and glowing lines (neural network style)
- Subtle circuit board patterns in background
- Floating geometric shapes (hexagons, circles) with gradient fills
- Light particles/sparkles effect around brain
- Clean sans-serif typography

COMPOSITION:
- Center: Abstract geometric brain illustration with neon glow effect
- Left side: Icon "🧠" or neural network symbol
- Right side: Floating UI elements suggesting quiz/statistics
- Bottom: Subtle line waves representing brain activity (EEG style)

LIGHTING & EFFECTS:
- Soft glow around main elements (blue/purple neon)
- Light bloom effect on accent colors
- Depth through subtle shadows
- Glass morphism elements (semi-transparent shapes with blur)

TEXT (if needed):
- "Всемогущие Нейроны" or "Нейротест" in modern sans-serif
- Clean, professional font like Inter, Montserrat, or Outfit

MOOD:
- Innovative, cutting-edge technology
- Scientific credibility
- Accessible and friendly
- Premium quality

AVOID:
- Cluttered design
- Too many colors
- Realistic brain imagery
- Stock photo look
- Childish elements
```

## Ключевые элементы для дизайна:

### Обязательно:
- ✅ Абстрактный геометрический мозг из точек и линий
- ✅ Неоновое свечение (синий/фиолетовый)
- ✅ Белый градиентный фон
- ✅ Чистая минималистичная композиция
- ✅ Футуристический научный стиль

### Опционально:
- 💡 Иконка 🧠 или символ нейронной сети
- 💡 Плавающие элементы UI (графики, чарты)
- 💡 Волны активности мозга (ЭЭГ)
- 💡 Частицы света
- 💡 Эффект стекломорфизма

### Избегать:
- ❌ Реалистичные изображения мозга
- ❌ Слишком много цветов
- ❌ Перегруженность деталями
- ❌ Стоковые фотографии
- ❌ Детские/мультяшные элементы

## Финальные рекомендации:

1. **Приоритет чистоте** — лучше меньше элементов, но качественнее
2. **Фокус на мозге** — главный элемент должен быть в центре внимания
3. **Баланс цвета** — не перегружать неоновыми акцентами
4. **Читаемость** — если есть текст, он должен быть хорошо читаем
5. **Профессионализм** — избегать игривых/детских элементов

Этот дизайн должен вызывать ассоциации с: инновациями, наукой, технологиями будущего, премиум-качеством, доступностью.

# Настройка бота через BotFather

## 1. Bot About (краткое описание)

```
Пройдите тест по нейрофизиологии и получите персональный гайд «5 нейротехник для продуктивности». Узнайте, как использовать возможности мозга на 100%! 🧠
```

## 2. Bot Description (полное описание)

```
🧠 Добро пожаловать в мир нейротехнологий!

Этот бот поможет вам:
✅ Оценить текущее состояние когнитивных функций
✅ Узнать свой нейропрофиль (Нейроновичок, Нейропрактик или Нейромастер)
✅ Получить персональный PDF-гайд с 5 научно обоснованными техниками
✅ Записаться на мероприятие «Всемогущие Нейроны 3»

📊 Короткий квиз — 7 вопросов за 3 минуты
📄 Практические техники для улучшения памяти, концентрации и стрессоустойчивости
🎯 Персональные рекомендации на основе ваших ответов

После прохождения теста вы сможете связаться с нашей командой прямо в этом чате!

Нажмите /start чтобы начать 🚀
```

## 3. Команды для BotFather (/setcommands)

```
start - Начать работу с ботом
quiz - Пройти квиз по нейрофизиологии
result - Показать мой результат
help - Справка и помощь
```

## 4. Короткое описание для поиска (Bot Short Description)

```
Квиз по нейрофизиологии + персональный гайд с 5 нейротехниками для продуктивности 🧠
```

---

## Как настроить через BotFather:

### 1. Установить описание (About)
```
/setabouttext
@NeuroEventsBot
<вставить текст из раздела 1>
```

### 2. Установить полное описание (Description)
```
/setdescription
@NeuroEventsBot
<вставить текст из раздела 2>
```

### 3. Установить короткое описание (Short Description)
```
/setshortdescription
@NeuroEventsBot
<вставить текст из раздела 4>
```

### 4. Установить команды
```
/setcommands
@NeuroEventsBot
<вставить список из раздела 3>
```

### 5. Установить изображение профиля (опционально)
```
/setuserpic
@NeuroEventsBot
<загрузить изображение с мозгом/нейронами>
```

---

## Дополнительные настройки:

### Включить inline mode (если нужно)
```
/setinline
@NeuroEventsBot
Искать информацию о нейротехниках...
```

### Установить кнопку меню
```
/setmenubutton
@NeuroEventsBot
Пройти квиз - https://t.me/NeuroEventsBot?start=menu
```

### Добавить privacy mode (для работы в группах)
```
/setprivacy
@NeuroEventsBot
Disable
```
**Важно:** Это нужно для работы relay-системы в супергруппе, чтобы бот видел все сообщения.

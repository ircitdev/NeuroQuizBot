# Инструкция по ручному перезапуску бота

## Если SSH недоступен

Если SSH-соединение с сервером не работает, используйте один из следующих способов:

### Способ 1: Веб-консоль хостинга

1. Зайдите в панель управления вашим сервером/VPS
2. Откройте веб-консоль или терминал
3. Выполните команды:

```bash
cd /root/NeuroQuizBot
docker compose restart
```

4. Проверьте статус:

```bash
docker ps --filter name=neuroquiz
docker logs neuroquiz-bot --tail 20
```

### Способ 2: Полная перезагрузка сервера

Если консоль тоже недоступна:

1. Перезагрузите сервер через панель управления
2. Подождите 2-3 минуты
3. Контейнер должен автоматически запуститься

### Способ 3: VNC или другой удалённый доступ

Если у вас есть VNC или другой способ подключения к серверу, используйте его для выполнения команд из Способа 1.

## После перезапуска

Проверьте работу бота:

1. Отправьте боту `/start`
2. Нажмите "📊 Пройти квиз"
3. Должен появиться первый вопрос с картинкой
4. Нажмите на любой вариант ответа
5. Должен появиться следующий вопрос

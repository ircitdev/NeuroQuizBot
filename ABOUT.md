# О проекте NeuroQuizBot

## Описание

**NeuroQuizBot** — это интерактивный Telegram-бот для мероприятия «Всемогущие нейроны: Когнитивное долголетие» (30 апреля 2026 года), который помогает квалифицировать потенциальных участников через увлекательный квиз по нейрофизиологии и автоматизирует работу с лидами.

## Основные возможности

### 🧠 Интерактивный квиз
- **7 вопросов** по нейрофизиологии с красочными иллюстрациями
- Удобные **inline-кнопки** для ответов
- Прогресс-бар выполнения квиза
- Время прохождения: **~3 минуты**

### 📊 Персонализированная оценка
Бот анализирует ответы и определяет когнитивный профиль пользователя:

| Профиль | Баллы | Описание |
|---------|-------|----------|
| 🌱 **Нейроновичок** | 6-12 | Мозг нуждается в перезагрузке |
| ⚡ **Нейропрактик** | 13-18 | Хорошая база с точками роста |
| 🏆 **Нейромастер** | 19-24 | Впечатляющий результат |

### 📄 Автоматическая генерация PDF
После прохождения квиза пользователь получает **два PDF-документа**:
1. **Персональный гайд** с рекомендациями на основе его профиля и приоритетных направлений
2. **Общая презентация** «5 нейротехник для продуктивности»

### 💬 CRM-система на базе Telegram
- **Автоматическое создание топика** в супергруппе для каждого нового лида
- **Полная карточка лида** с результатами квиза, контактными данными и источником трафика
- **Двусторонняя переписка**: менеджер пишет в топик → пользователь получает сообщение, и наоборот
- Поддержка текста, фото, документов, голосовых сообщений

### 📈 Аналитика и статистика
Для администраторов доступна команда `/stats` с данными:
- Общее количество пользователей
- Количество завершённых квизов
- Средний балл
- Распределение по профилям
- Источники трафика (UTM-метки)

### 📢 Массовая рассылка
Администраторы могут отправлять broadcast-сообщения всем пользователям, прошедшим квиз, через команду `/broadcast`.

## Технические характеристики

### Технологии
- **Python 3.11+** — основной язык разработки
- **aiogram 3.x** — современный асинхронный фреймворк для Telegram Bot API
- **SQLite** — легковесная база данных
- **ReportLab** — генерация PDF-документов с поддержкой кириллицы
- **Docker** — контейнеризация для простого деплоя

### Архитектура
- **FSM (Finite State Machine)** для управления состояниями квиза
- **Модульная структура** с разделением на handlers, services, keyboards
- **Асинхронная обработка** всех операций
- **Relay-система** для пересылки сообщений между пользователями и менеджерами

### Безопасность
- Токены и чувствительные данные хранятся в `.env` файле
- Доступ к админ-командам только для авторизованных пользователей
- Валидация данных на всех этапах

## Пользовательский опыт

### Типичный сценарий использования:

1. 👤 **Пользователь** нажимает кнопку «Получить в Telegram» на сайте мероприятия
2. 🤖 **Бот** приветствует его и предлагает пройти квиз
3. 📝 **Пользователь** отвечает на 7 вопросов с иллюстрациями (занимает 3 минуты)
4. 🎯 **Бот** подсчитывает результат и показывает персональный профиль
5. 📄 **Бот** отправляет два PDF-документа с рекомендациями
6. 💼 **Система** автоматически создаёт топик в CRM с полными данными лида
7. 👨‍💼 **Менеджер** видит новый топик, изучает профиль и начинает общение
8. 💬 **Общение** происходит через бота: менеджер в топике ↔ пользователь в личных сообщениях

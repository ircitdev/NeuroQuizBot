# История изменений NeuroQuizBot

## [2026-02-26] - Обновление изображений и PDF

### ✨ Добавлено

#### Иллюстрации для квиза
- Добавлены изображения для всех 7 вопросов квиза (q1.jpg - q7.jpg)
- Реализована автоматическая отправка фото с вопросами
- Общий размер изображений: 538 KB
- Формат: JPEG, оптимизированные для быстрой загрузки

#### Исправление кодировки PDF
- Подключен шрифт **Montserrat-Regular.ttf** (240 KB) для корректного отображения кириллицы
- Добавлен **Montserrat-Black.ttf** (252 KB) для жирных заголовков
- Реализован fallback на Helvetica если шрифты недоступны

#### Логотип в PDF
- Добавлен **logo.jpg** (93 KB) в конец каждого персонального PDF
- Логотип масштабируется пропорционально (ширина 8 см)
- Центрируется по горизонтали

#### Команда массовой рассылки
- Добавлена команда `/broadcast` для администраторов
- Поддержка текста, фото, видео, документов
- Rate limiting (50ms между сообщениями)
- Статистика: успешно/заблокировано/ошибки
- FSM для управления потоком рассылки

### 📝 Документация

Добавлены руководства:
- **BROADCAST_GUIDE.md** - Полное руководство по массовой рассылке
- **QUIZ_IMAGES.md** - Документация по изображениям квиза
- **PDF_SETUP.md** - Настройка PDF генерации и шрифтов
- **CHANGELOG.md** - История изменений

### 🔧 Технические изменения

#### bot/handlers/quiz.py
- Добавлена поддержка отправки изображений с вопросами
- Автоматическая проверка наличия изображений
- При наличии изображения используется `answer_photo` с caption
- При отсутствии - обычное текстовое сообщение

#### bot/services/pdf_handler.py
- Регистрация TTF шрифтов через `pdfmetrics.registerFont()`
- Использование Montserrat для всех стилей текста
- Добавление изображения логотипа через `reportlab.platypus.Image`
- Обработка ошибок при отсутствии файлов

#### bot/handlers/broadcast.py (новый)
- FSM состояния для управления рассылкой
- Отправка всем пользователям из БД (кроме отправителя)
- Подсчет успешных/неудачных отправок
- Обработка блокировок и ошибок
